Bienvenue sur notre site

Notre initiative privée vise à recueillir et examiner les demandes de personnes souhaitant obtenir des informations sur un programme d'entraide en Haïti.

Notre initiative

Nous souhaitons étudier les demandes selon les ressources réellement disponibles et des critères clairement communiqués. Envoyer une demande ne garantit pas l'obtention d'une aide.

Formulaire d'inscription

Remplissez les informations nécessaires pour que notre organisation puisse examiner votre demande.

L'envoi sera opérationnel après validation de l'adresse par FormSubmit. Ne saisissez pas de mot de passe, de code bancaire ou de document d'identité dans ce formulaire.

Sécurité et confidentialité

  • La soumission d'une demande est gratuite.
  • Les informations reçues doivent rester confidentielles.
  • Une demande doit être examinée avant toute décision.
  • Aucun code OTP n'est généré ou validé par cette page.

Si une vérification par code est mise en place ultérieurement, elle devra utiliser un système sécurisé et ne jamais demander à une personne de communiquer un code bancaire ou un mot de passe.

Cette organisation est indépendante des institutions publiques. Aucune aide n'est garantie par le simple fait de s'inscrire.
